# **[JavaScript] 이벤트 버블링과 stopPropagation()으로 문제 해결하기**

웹 개발을 하다 보면 이벤트 버블링(Event Bubbling)으로 인해 의도치 않은 동작이 발생하는 경우가 있습니다. 오늘은 버튼 클릭 시 이벤트 버블링을 중지하여 원하는 동작만 실행되도록 하는 방법을 다뤄보겠습니다.

---

## **문제 상황**

HTML 구조는 다음과 같습니다:

```html
<div class="top-sales-item" onclick="navigateToPage();">
    <!-- 상품 정보 -->
    <button id="cart_btn" onclick="putItemsIntoCart();" data-product-no="${bestitem.PRDCTNO}">
        <img src="../resources/img/icon/cart.png">
    </button>
</div>
```

- **`<div class="top-sales-item">`**: 이 div를 클릭하면 페이지가 이동하는 `navigateToPage()` 함수가 호출됩니다.
- **`<button id="cart_btn">`**: 이 버튼을 클릭하면 Ajax를 통해 장바구니에 상품을 추가하는 `putItemsIntoCart()` 함수가 호출됩니다.

### 문제:
버튼을 눌렀을 때 `putItemsIntoCart()`가 실행되면서, 부모 요소 `<div class="top-sales-item">`의 `onclick` 이벤트도 함께 동작하여 **페이지 이동**이 발생합니다. 결국, 사용자는 장바구니에 상품을 추가하지 못하고 페이지가 이동되는 문제를 겪게 됩니다.

---

## **해결 방법: 이벤트 버블링 중지**

**이벤트 버블링(Event Bubbling)**은 특정 HTML 요소에서 이벤트가 발생했을 때 해당 이벤트가 부모 요소로 전파되는 현상입니다. 이를 중지하기 위해 JavaScript에서는 `event.stopPropagation()` 메서드를 사용할 수 있습니다.

---

### **수정된 코드**

```html
<div class="top-sales-item" onclick="navigateToPage();">
    <!-- 상품 정보 -->
    <button id="cart_btn" onclick="event.stopPropagation(); putItemsIntoCart();" data-product-no="${bestitem.PRDCTNO}">
        <img src="../resources/img/icon/cart.png">
    </button>
</div>
```

### **변경된 부분**
1. **`event.stopPropagation();`**:
   - 버튼 클릭 시 이벤트 버블링을 중지하여 부모 요소의 `onclick` 이벤트가 실행되지 않도록 합니다.
   
2. **결과**:
   - 버튼을 클릭하면 `putItemsIntoCart()`만 실행되고, 페이지 이동을 담당하는 `navigateToPage()`는 동작하지 않습니다.

---

## **코드 설명**

### **1. 이벤트 객체(event)란?**
`event` 객체는 JavaScript에서 자동으로 제공하는 객체로, 이벤트와 관련된 다양한 정보와 메서드를 포함합니다. 이를 통해 이벤트의 기본 동작을 중지하거나, 전파 방식을 제어할 수 있습니다.

### **2. 이벤트 버블링 흐름**
- 버튼 클릭 → 이벤트가 `<button>`에서 발생 → 이벤트가 `<div>`로 전파 → `onclick="navigateToPage()"` 실행
- 이 흐름을 **`event.stopPropagation()`**으로 차단하여 `<div>`로의 전파를 막습니다.

---

## **추가 고려사항**
- **이벤트 위임(Event Delegation)**:
  - 버튼 클릭 이벤트를 상위 요소에서 관리하려는 경우, `stopPropagation`을 사용하면 이벤트 위임 방식이 차단될 수 있습니다. 이러한 구조에서는 다른 설계를 고려해야 합니다.

- **`event.preventDefault()`와의 차이**:
  - `preventDefault()`는 기본 동작(예: 링크 클릭 시 페이지 이동)을 막는 것이고, `stopPropagation()`은 이벤트 전파를 차단하는 것입니다.

---

## **결론**

이벤트 버블링으로 인해 발생하는 문제는 종종 복잡한 UI에서 발생할 수 있습니다. 이러한 상황에서 `event.stopPropagation()`은 간단하고 효과적인 해결책을 제공합니다.

**적용 예시**: 장바구니 버튼, 모달 창의 내부 버튼, 드롭다운 메뉴 등에서 유용하게 사용됩니다.
